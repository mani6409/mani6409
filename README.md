### 🚀 What I'm building now

**[SSB Academy](https://github.com/gaurav-vv/EliteCadet-ssb)**: a preparation platform for India's Services Selection Board
interview, serving students, mentors, academies and a platform team. I built most of the platform
end to end:

- **Access and isolation:** role-based access (RBAC) with academy isolation enforced in Postgres row-level security
- **Training workflow:** batches, session scheduling, assessments and mentor feedback
- **Insight:** progress tracking, role dashboards, notifications and platform analytics
- **Practice:** a 5-day practice journey with answers saved to each student's account

`Next.js 16` · `React 19` · `TypeScript` · `Supabase / PostgreSQL` · `Tailwind CSS` · `Vitest` · `Playwright`
